# DevSec-AI Nexus 🛡️

أداة أمنية ذكية لفحص الأكواد البرمجية (Python) واكتشاف الثغرات الشائعة قبل رفعها أو تشغيلها.

## 🚀 المميزات
- اكتشاف كلمات المرور والتوكنز المسربة (Hardcoded Secrets).
- اكتشاف استخدام الدوال الخطيرة (مثل os.system و eval).
- اكتشاف احتمالية وجود ثغرات (SQL Injection).
- واجهة مستخدم سهلة الاستخدام لفحص الأكواد مباشرة.

## 🛠️ التقنيات المستخدمة
- الخلفية (Backend): Python, FastAPI, Uvicorn
- الواجهة (Frontend): HTML, CSS, JavaScript
- أداة الفحص: Regex (التعبيرات النمطية)
